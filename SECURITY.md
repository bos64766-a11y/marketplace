# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in SNABTASH, please send an email to:
**security@snabtash.uz** or **admin@snabtash.uz**.

Please include:
- Description of the vulnerability and impact.
- Steps to reproduce or proof-of-concept.
- Any suggested mitigations.

We take security issues seriously and will respond promptly within 48 hours.
